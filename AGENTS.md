- Layer privacy: full actor data lives in layer_actor_private (managers only); apply_layer_privacy rewrites the public layer_actors row per the layer's data_source_settings.privacy flags — why: keeps reserved data out of the public API.
- Biblioteca files are opened only through the library-file backend function, which signs URLs for catalogued documents bound to their uploader (or the curated SPG seed folder); the bucket has no public read rule — why: shared reading without exposing storage objects directly.
- Activity RSS reads events anonymously with explicit public fields, reads enabled settings server-side only for filtering, and applies layer/year/past visibility before selecting the latest 100 publications — why: syndication must never reveal private records or bypass layer visibility.
- Map exports use server-validated per-user/per-layer approvals with manager review and revocation; export only privacy-rewritten public fields from enabled layers — why: client-side downloads must not bypass export permissions or reveal reserved data.
- RSS and map exports share activity visibility code under the edge-functions shared directory — why: deployed functions cannot import sibling function directories and must agree on hidden activities.
